# Atemingo Launcher

Minecraft için Türkçe başlatıcı. **Windows ve Linux** sürümleri yayında.

Web sitesi: https://atemingo.github.io/AtemingoLauncher/

## Hangi dosya hangi sistem için?

| Dosya | Platform | Kurulum |
| --- | --- | --- |
| [AtemingoLauncher-setup.exe](https://github.com/atemingo/AtemingoLauncher/releases/download/minecraft/AtemingoLauncher-setup.exe) | **Windows 10/11 (64-bit)** | İndirip çalıştırın |
| [AtemingoLauncher-2.0.0-linux-x64.AppImage](https://github.com/atemingo/AtemingoLauncher/releases/download/v2.0.0-linux/AtemingoLauncher-2.0.0-linux-x64.AppImage) | **Linux (64-bit) — taşınabilir** | `chmod +x AtemingoLauncher-2.0.0-linux-x64.AppImage` ve çift tıklayın |
| [AtemingoLauncher-2.0.0-linux-x64.deb](https://github.com/atemingo/AtemingoLauncher/releases/download/v2.0.0-linux/AtemingoLauncher-2.0.0-linux-x64.deb) | **Linux — Debian / Ubuntu (64-bit)** | `sudo apt install ./AtemingoLauncher-2.0.0-linux-x64.deb` |

## Sürümler

- **Windows:** [Releases → minecraft (setup.exe)](https://github.com/atemingo/AtemingoLauncher/releases/tag/minecraft)
- **Linux:** [Releases → v2.0.0-linux (AppImage & DEB)](https://github.com/atemingo/AtemingoLauncher/releases/tag/v2.0.0-linux)

> Windows için `AtemingoLauncher-setup.exe`, Linux için `AtemingoLauncher-2.0.0-linux-x64.AppImage` veya `.deb` indirin. Bu dosyalar birbirinin yerine çalışmaz.

**English:** `AtemingoLauncher-setup.exe` is for **Windows 10/11 (64-bit)**. The `AtemingoLauncher-2.0.0-linux-x64.AppImage` and `.deb` files are for **Linux (64-bit)**.
